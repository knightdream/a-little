# 角色动作与 Unity 接入说明

更新：2026-10-13。本文件记录已经确认的操作方向、当前实现，以及尚需完成的接入工作；本次整理不修改游戏逻辑。

## 固定高度跳跃与斜跳

每次起跳使用相同的纵向初速度，松开跳跃键不缩短跳高。横向输入独立控制：不按方向键原地跳，按左或右键形成斜向运动；空中可停止横移或反向。人物仍保持直立，向左时翻转图像，不按运动轨迹旋转整个人，也不需要单独制作斜跳动画。

```text
水平方向：vx = 输入方向 × 移动速度
起跳瞬间：vy = 固定起跳速度
起跳之后：重力持续改变 vy
```

无碰撞、重力不变时，相对起跳点的理论高度为 H = v₀² / (2g)，同高度起落的理论滞空时间为 T = 2v₀ / g。横向速度不改变纵向轨迹；持续按方向时跳远约为 |vx| × T。碰到天花板会提前结束上升，落在高低不同的平台也会改变滞空时间。“固定高度”不是无视地形碰撞、强制到达某个世界坐标。

## 当前 Unity 已实现的部分

[PlayerController.cs](../newgame/Assets/Scripts/Player/PlayerController.cs) 的 `FixedUpdate` 每次将水平速度设置为 `move * speed`，默认 speed=7；允许起跳时将纵向速度设置为 jumpSpeed=12，之后由 Rigidbody2D 重力控制。地面与空中使用相同横向响应，无加减速惯性。松开方向键即停止横移；没有松开空格截断上升的代码。

起跳带 0.12 秒输入缓冲与 0.1 秒土狼时间，默认重力倍率为 3，下降速度上限为 20。具体物理配置以代码和项目设置为准，网页预览的像素参数不能直接作为 Unity 世界单位使用。

当前主角由 [GameBootstrap.cs](../newgame/Assets/Scripts/Core/GameBootstrap.cs) 创建，仍是青色方块。J 键仍连续发射子弹，没有扳手近战、角色动画播放器或 Animator 状态机。

## 接入时的处理方案（待实现）

1. 将透明帧放入 Unity 的 Assets，设置 Texture Type 为 Sprite (2D and UI)，统一 Pixels Per Unit。独立帧用 Single；序列图用 Multiple，按对应单帧尺寸切片。
2. 统一比例与脚底基准。当前素材地面 y=432，行走髋部基准 x=220，跑跳 x=210，攻击 x=300。应在预处理时统一画布与根节点，或分别设置等效 pivot/偏移；不能全部按画布中心对齐。PNG 的 y 从上往下，Unity Sprite pivot 的 y 从下往上，转换时要注意。
3. 保留物理根节点上的 Rigidbody2D 与 Collider2D，另建 Visual 子节点显示动画。当前占位物体缩放为 0.7×1.2，接入时应显式设置碰撞盒尺寸、重置根节点缩放，避免角色图片被拉伸。翻转仅作用于视觉节点，不改变碰撞体。
4. 依据输入、接地状态和纵向速度驱动动画。水平移动播放行走或跑步，具体区分按键与速度规则尚未确定；静止可暂用站姿帧。上升用上升段、下落用下落段，检测真实接地后播放落地段。不同高度平台下落不能依赖整段跳跃动画的固定时长。
5. 动画不推动物理根节点；跳跃纵向位移由 Rigidbody2D 完成。HTML/GIF 中用于展示跳高的整体位移不能再次叠加到游戏角色上。网页中的起跳准备与落地缓冲时长属于预览参数，是否延迟游戏输入尚未确认。
6. 扳手近战需单独实现挥击判定窗口、朝向对应的攻击区域、单次攻击命中过的敌人记录，以及取消、受伤打断与冷却规则。动画切到指定帧只触发判定，不代表画面中的扳手自动具备伤害。J 键射击是否替换、攻击是否允许在空中使用，尚未决定。

这些素材仍有部件拼接和僵硬感，可作为程序原型资源，未达到最终美术品质。目前没有将这些动画接入 Unity。

## 接入后的验收清单

- 原地、向左、向右起跳在相同地形下达到相同高度，短按和长按空格高度相同。
- 空中松开方向键与反向操作只改变横向运动；天花板、平台及落地碰撞正常。
- 切换行走、跑步、跳跃、攻击时人物比例与根节点不跳变，左右翻转不改变碰撞体。
- 上升转下落、提前落到高平台、从平台走下时，动作都跟随真实运动状态。
- 攻击只在有效窗口伤害范围内敌人，同一次攻击不重复扣血，收招能回到正确状态。
