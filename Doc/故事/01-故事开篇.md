# 醒来又是新的一天

## 游戏主旨

主角在陌生公寓醒来，发现自己无法离开。玩家以公寓为据点，进入都市传说中的异常场景，通过探索、战斗与逃生完成十场试炼，获得离开资格。

核心体验是横版动作探索，减少复杂解谜，用场景变化和简短提示推进剧情。

## 开场流程

1. **房间醒来**：玩家开始控制角色，熟悉移动。
2. **探索房间**：找到钥匙，学习拾取和开门。
3. **走出房间**：探索走廊、下楼，认识公寓布局。
4. **尝试离开**：穿过大门却回到房间，发现自己被困。
5. **了解处境**：与住户简短交谈，得知需要完成公寓任务才能离开。
6. **领取任务**：公告栏出现第一场任务，提示前往一楼候车。
7. **准备出发**：玩家确认准备完成，切换到夜晚，上车进入第一关。

## 后续游戏循环

公寓休整 → 接受任务 → 进入关卡 → 探索与战斗 → 完成目标并逃生 → 返回公寓 → 累计试炼进度。

完成十场试炼后进入最终离开流程，具体结局待定。
