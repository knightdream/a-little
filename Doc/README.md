# 灵异公寓游戏设计

游戏使用 Unity 与 C# 开发，以横版动作探索为核心，结合都市传说与表里世界。

已确定的核心方向：单一女性主角被困在公寓，通过十场动作探索试炼争取逃离，减少复杂解谜。公寓承担任务发布、人物关系与主线推进。

作品定位参考用户提出的《地狱公寓》式任务体验。下列人物、地点、规则和事件均为新创提案；不是该小说的剧情梳理或改编稿。十场任务的具体内容仍可调整。
