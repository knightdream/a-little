# 黑发 A 扳手攻击

沿用黑发 A 行走修正版的透明部件。24 帧单次挥击，先举起扳手、向前砸下，再收回站姿。仍为部件动画预览，未接入 Unity、伤害判定或敌人反馈。

- `攻击.gif`：分段节奏预览，挥击较快，收招后停顿以方便反复观看。
- `攻击慢放.gif`：每帧 120 毫秒。
- `预览.html`：均速播放、慢放和逐帧查看。
- `attack/00.png` 至 `23.png`：640×490 透明帧，地面基准 y=432，初始髋部 x=300。画布比跑跳宽，接入时须统一根节点，不能直接按画布中心对齐。
- `attack-24.png`：6×4 透明序列图。
- `build_attack.py`：生成脚本，复用相邻行走目录的部件，需要 Pillow、NumPy。

第 1–9 帧蓄力，第 10–16 帧挥击，第 17–24 帧收招。首尾站姿一致，脚底固定，身体向前转移重心。检查所有帧未越出画布，首尾像素差不超过 1，并查看关键姿势图。

这是单次普通攻击候选，不含连招、特效、音效、命中停顿。可见部件接缝和肢体遮挡，后续再细修。
