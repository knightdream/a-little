# 黑发 A 动作预览

行走已被[行走修正版](../黑发A行走修正版/README.md)替代，本目录旧行走和旧并排预览仅保留作对比。跳跃和攻击尚未修订。

采用已选的黑发 A 女主，黄色外套、红叉发夹、黑色宽裤和扳手，沿用简洁暗色卡通方向。

- `动作并排预览.gif`：走路、跳跃、攻击并排循环，预览速度 12.5 帧每秒，每轮 1.92 秒。
- `动作并排预览.mp4`：同一预览的视频版，编码 25 fps 不代表增加了原画。
- `walk.gif`、`jump.gif`、`attack.gif`：单项预览。
- `walk/`、`jump/`、`attack/`：每项 24 张透明 PNG，400 × 400。
- `*-24.png`：整理后的六列四行透明图集。
- `源图/`：图像工具的原始结果，保留未采用的攻击初稿供追溯。
- `assemble.py`：切片、脚底对齐和合成脚本。

## 帧数与局限

走路、跳跃分别由源图中的 24 个姿势切片；攻击修正版实际得到 20 个姿势，通过复用起手、冲击和收势帧形成 24 帧时间线，并非 24 张不同攻击原画。

跳跃预览额外加入展示用的垂直轨迹，不能直接当作游戏跳跃物理。正式接入 Unity 时应由角色控制器决定位置，并根据起跳、上升、下落、落地切换动画。

本版用于评价角色与动作方向。仍存在生成式逐帧造型漂移、步态连续性不足以及武器大小不完全一致的问题，不是可直接发布的最终资产。尚未接入 Unity，也没有实现攻击命中框。

动作素材由内置 image_gen 生成，提示词保存在同目录。GIF 与 MP4 已完成输出检查；未做正式游戏内手感验收。
