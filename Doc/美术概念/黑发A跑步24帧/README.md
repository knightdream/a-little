# 黑发 A 跑步动画

沿用已确认的黑发 A 造型和行走修正版的透明部件，通过关节旋转与双段腿部逆运动学生成 24 帧循环。属于部件动画预览，不是逐帧重绘。

- `跑步.gif`：25 fps，完整循环 0.96 秒。
- `跑步慢放.gif`：每帧 120 毫秒。
- `跑步.mp4`：视频预览。
- `预览.html`：播放、调速、逐帧查看。
- `run/00.png` 至 `23.png`：440 × 490 透明单帧。
- `run-24.png`：6 列 × 4 行透明序列图。
- `八个关键姿势.png`、`步态检查.gif`、`步态数据.json`：检查资料。

相较行走，躯干前倾、步幅和摆臂增大、肘部弯曲、后脚抬高；每条腿支撑时间为周期的 36%，第 10–12 和 22–24 帧双脚离地。左右腿相差半个周期，同侧手脚反向运动。持扳手手臂摆幅略小。

已检查 24 帧互不相同、完整周期端点一致、同侧手脚反向、左右腿交替、支撑脚高度及腾空阶段；并查看关键姿势图。仍可见部件拼接感，衣服和头发尚无独立跟随动画，未接入 Unity。

运行 `python3 build_run.py` 可重建 PNG 与 GIF，需要 Pillow、NumPy；部件读取自相邻 `黑发A行走修正版/部件/`。视频需另用 FFmpeg 从 GIF 导出。
