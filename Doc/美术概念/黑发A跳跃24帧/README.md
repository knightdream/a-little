# 黑发 A 固定高度跳跃

沿用行走与跑步的黑发 A 部件，24 帧动画：0–3 起跳准备、4–19 空中姿势、20–23 落地缓冲。首尾均为同一站姿，有意重复便于衔接。仍是部件动画，衣发没有独立跟随，尚未接入 Unity。

打开 `预览.html`：A/D 或左右箭头移动，空格跳跃，亦可使用屏幕按钮。每跳高度固定 140 预览像素，空中可左右调整、松开方向键停下横移，也可转向。松开空格不会提前下落，按住空格不连跳，无二段跳。起跳准备 0.12 秒，落地缓冲 0.16 秒。

纵向公式 `h(t)=v₀t−gt²/2`，`g=1400`，`v₀=√(2gH)`；横移速度 230 像素/秒，与纵向独立。此处采用即时横移响应，没有惯性；参数属于预览设置，最终游戏手感可再调。虚线表示角色根部的固定最高位移，脚部收腿不参与高度计算。

- `跳跃.gif`：原地跳跃动作预览；播放节奏为展示动作设置。
- `跳跃慢放.gif`：慢放。
- `jump/`：24 张 440×490 透明帧，位置基准固定，不包含实际世界纵向位移。
- `jump-24.png`：6×4 序列图。
- `motion.js`：可操作预览的运动参数与公式。
- `build_jump.py`：生成脚本，依赖 Pillow、NumPy 和相邻行走修正版部件目录。

检查：首尾站姿一致，关键姿势图已查看；数值验证跳跃顶点 140、落点 0，以及左移、右移、原地三种输入不影响纵向轨迹。交互预览与 GIF 的播放时序独立，实际接入时应由速度/落地状态驱动动画。
