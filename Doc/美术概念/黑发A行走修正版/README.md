# 黑发 A 行走修正版

修复上一版缺少摆臂、左右腿交替不明确和帧间不连贯的问题。沿用黑发 A，改用固定图形部件、双腿反向相位与两段式腿部运动求解生成 24 帧。本版是部件动画预览，不是重新手绘的 24 张原画。

## 查看

- `行走修正版.gif`：20 fps，每个循环 1.2 秒。
- `行走慢放.gif`：每帧 120 毫秒，便于观察。
- `行走修正版.mp4`：视频预览。
- `预览.html`：播放、暂停、调速、逐帧查看，直接用浏览器打开即可。
- `walk/`：24 张透明 PNG，每张 440 × 490。
- `walk-24.png`：六列四行透明图集。
- `八个关键姿势.png`：从 24 帧中每隔 3 帧取样。
- `步态检查.gif`、`步态数据.json`：关节轨迹辅助检查，青色为近侧，橙色为远侧。

## 动作规则

左右腿相隔半个周期。每条腿约六成周期为地面支撑、四成为抬脚向前跨步，形成短暂双脚支撑，没有双脚同时腾空的跑步阶段。同侧手臂与腿反向摆动；近侧手持扳手，摆幅小于另一只手。靴子与小腿分别控制，支撑期鞋底保持水平。

检查通过：24 帧输出、循环 t=0 与 t=1 一致、双腿轨迹反向、同侧手脚轨迹反向、支撑期脚底高度固定。另检查了八个关键姿势的外观。预览是原地行走，正式移动速度必须与支撑脚向后的速度匹配，才能避免游戏中脚底滑动。

## 仍需精修

关节处仍有少量部件拼接感，衣摆和发丝尚未做独立跟随动画。当前处理的是动作方向与连续性，不是最终逐帧美术。未修改跳跃和攻击，未接入 Unity。

角色部件由内置 image_gen 生成并修订，最终提示词保存于同目录；`build_walk.py` 负责确定性姿势变换、切片和预览输出。原有行走初稿保留在相邻 `黑发A动作24帧` 目录，后续以本版行走为准。
